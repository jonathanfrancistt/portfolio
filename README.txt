CHAMELEON PORTFOLIO
===================

What's in this folder
  index.html               The website. Open it in a browser to view it.
  projects.js              YOUR WORK LIST. The only file you edit to add work.
  work/                    Drop your images and videos here.
  assets/                  The logo and browser-tab icon.
  build-single-file.py     Optional. Bundles everything into one file to email.

To add a piece of work
  1. Put the file in the work folder.
  2. Open projects.js in VS Code, copy any line in PROJECTS, paste it at the
     top of the list, and change the file name, title and category.
  3. Save, then refresh index.html in your browser.
  (More detail and tips are at the top of projects.js.)

To send it to a client
  Option A: Upload this whole folder to a web host (Netlify Drop, GitHub Pages,
            your own hosting) and send the link.
  Option B: Run build-single-file.py. It creates Chameleon_Portfolio.html, one
            file with everything inside that you can email or upload anywhere.
            Run it again after each change.

Before sending to clients
  In projects.js set  SHOW_PLACEHOLDERS = false  to hide the
  "Add your work here" tiles and any empty categories.
